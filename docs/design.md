# Moon TaskForge architecture

Status: development plan; functionality must be checked against release documentation.

目标：形成本地任务图从输入变化、选择任务、执行到增量缓存与失败报告的完整构建流程。

核心模块：任务图与校验；规划及拓扑调度；本地进程适配；有界并发；输入输出指纹；缓存与失效传播；超时/取消/重试；恢复记录和 CLI。处理进程退出与输出文件的真实结果，计划器本身可跨后端测试。

三个场景：代码生成与编译链；文档构建与链接检查；离线图片或静态资产处理。实际运行固定测试命令，记录首次执行、无变化缓存命中及单输入变更后的最小重建。

验收：一百任务图的执行顺序遵守依赖；失效集合与独立参考一致；缓存命中时产物摘要仍核验。失败验证覆盖环、任务失败、进程超时、伪造缓存、产物丢失和路径包含空格。只在专用测试目录执行预设命令。十月不做分布式调度、容器集群或 AI 多代理工作流。
